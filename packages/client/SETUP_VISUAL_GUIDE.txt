    use require('crypto')

Problem: "DocStack library not loaded"
Solution:
  1. npm run build           (create dist/)
  2. Check /dist/index.js exists
  3. Verify webServer running
  See: e2e/README.md#Troubleshooting

Problem: "Crypto not initialized"
Solution:
  1. Library uses helpers automatically
  2. Should work in browser and Node.js
  See: e2e/TYPESCRIPT_NOTES.ts

Problem: "Port 3000 already in use"
Solution:
  1. Edit playwright.config.ts
  2. Change webServer.url port
  3. Edit package.json serve:test port
  See: e2e/README.md#Port Already in Use

Problem: "IndexedDB errors"
Solution:
  1. Tests use docStackPage fixture
  2. This ensures browser environment
  3. Check browser privacy settings
  See: e2e/README.md#IndexedDB Access Issues
