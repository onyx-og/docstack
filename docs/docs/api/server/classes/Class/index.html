close()​

close(): void;

Defined in: shared/src/utils/stack/class/index.ts:55

Releases this instance's live document subscription.

Subscribing is not free: the handle keeps its handler - and everything that handler closes over - reachable for as long as the stack lives. Close a Class that was built outside the stack's cache (getClass(name, true), or an entry a class list has replaced) once it is no longer needed. Afterwards the instance stops emitting doc events; its data methods still work. Safe to call twice.

Returns​

void

Example​

const snapshot = await stack.getClass('Task', true);
// ...
snapshot.close();
