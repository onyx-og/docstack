Class: RemoteStack

Defined in: packages/client/src/core/remote-stack.ts:217

A stack that lives on a DocStack server (spec 03 §8).

The same contract as ClientStack where the hooks and Class reach it - getClass, getDomain, getClassNames, addClass, findDocuments, query, createDoc(s), deleteDocument, subscribeClassDocs - over the server's API surface and a live feed. Nothing is replicated; every read and write runs on the host under the caller's session, so what comes back is what that principal may see. Members that only a local engine has (db, sync, keys, transactions) throw RemoteStackError.

static connect(options): Promise<RemoteStack>;

Defined in: packages/client/src/core/remote-stack.ts:257

Opens a remote stack: verifies the server answers for it (the class list, which also proves the grant reaches the stack) and returns the stack ready to use.

Example​
